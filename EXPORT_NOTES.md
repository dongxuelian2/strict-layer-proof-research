# Export notes

This repository is an archival dump of the Strict Layer proof-research history recovered from the project file library through 2026-08-20.

## Coverage

- Named Markdown proof reports and stage archives were recovered through `105-R40-FINAL-FAILURE-REPORT.md`.
- Proof scripts, verification scripts, logs, JSON registries, certificates, SHA manifests, and frozen ZIP bundles were retained when present.
- The earlier curated Strict Layer archive is retained in the top-level numbered directories (`00-foundation` through `50-state-and-computation`).
- Later raw-stage material is retained under `archive-by-series/` without rewriting its mathematical contents.

## Library-only writing blocks

The project file library also contains many generic duplicate writing-block objects named like `粘贴的 markdown (1)。md(...)`. The file service does not expose their raw bytes through materialization (403/Forbidden in prior retrieval attempts). They are not fabricated in this repository. Named phase reports corresponding to the research timeline were recovered and archived instead.
