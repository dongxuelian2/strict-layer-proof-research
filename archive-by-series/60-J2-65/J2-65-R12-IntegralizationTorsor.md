# J2-65-R12 — Integralization Torsor Note

R12 constructs an explicit rational Gaussian witness

\[
z_{\mathbf Q}\in\mathbf Q(i),\qquad N(z_{\mathbf Q})=N.
\]

R10 uses an integral witness

\[
z_{\mathbf Z}\in\mathbf Z[i],\qquad N(z_{\mathbf Z})=N.
\]

The exact bridge is

\[
\mathcal T_{\rm int}(z_{\mathbf Q})
=
\{\varepsilon\in\mathbf Q(i)^1:
\varepsilon z_{\mathbf Q}\in\mathbf Z[i]\}.
\]

If \(z_{\mathbf Z}\) is any integral representation, then
\(\varepsilon=z_{\mathbf Z}/z_{\mathbf Q}\) has norm one. Thus every integral
representation lies in this torsor.

The missing datum is therefore not a rational Brauer-to-Gaussian isomorphism.
It is the noncanonical integralization choice. Forgetting this choice forgets
source-attached phase and radial primitive data.
